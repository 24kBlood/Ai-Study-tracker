# 🎓 AI Study Tracker & Planner

Современная платформа для отслеживания прогресса обучения ИИ-моделей и личной учёбы пользователя с «Cyber-Glass» дизайном.

## 🚀 Возможности

| Модуль | Описание |
|--------|----------|
| **Дашборд** | Графики часов учёбы, статистика по дням/неделям, недавние сессии |
| **Предметы и темы** | Создание предметов, целевые часы, прогресс-бары, старт таймера |
| **Методы учёбы** | Pomodoro, Flash Cards, метод Фейнмана, Active Recall, интервальное повторение |
| **Отслеживание ИИ** | Графики потерь (Loss) и точности (Accuracy) по эпохам, загрузка JSON/CSV логов |
| **Лист заданий** | Приоритеты, дедлайны, статусы, фильтрация, drag-and-drop |
| **AI Генератор плана** | Генерация учебного плана по предмету с методами и часами |
| **Настройки** | Тёмная/светлая тема, язык, уведомления |

## 🎨 Дизайн

- **Cyber-Glass стиль**: тёмная тема (`#0f172a`), стеклянные панели (`backdrop-filter: blur`), неоновые акценты (`#38bdf8`)
- **Адаптивность**: мобильные-first, работает на десктопе и мобильных устройствах
- **Анимации**: плавные переходы, hover-эффекты, анимация таймера

## 🛠 Технологический стек

- **Frontend**: React 18 + TypeScript + Vite
- **Стили**: Tailwind CSS
- **Графики**: Recharts
- **Иконки**: Lucide React
- **Анимации**: CSS (встроенные в Tailwind)
- **Типизация**: TypeScript

## 📦 Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/ВАШ_ПОЛЬЗОВАТЕЛЬ/ai-study-tracker.git
cd ai-study-tracker
```

### 2. Установка зависимостей

Убедитесь, что у вас установлен [Node.js](https://nodejs.org/) (версия 18+).

```bash
npm install
```

### 3. Запуск в режиме разработки

```bash
npm run dev
```

Откройте браузер по адресу: **http://localhost:5173**

### 4. Сборка для продакшена

```bash
npm run build
```

Готовая сборка появится в папке `dist/`. Можно развернуть на Vercel, Netlify, GitHub Pages или любом другом статическом хостинге.

### 5. Предпросмотр сборки

```bash
npm run preview
```

## 🎯 Как пользоваться

### Отслеживание учёбы
1. Создайте предмет в разделе «Предметы»
2. Добавьте темы внутри предмета
3. Запустите таймер на теме (Pomodoro 25/5 или ручной режим)
4. Следите за прогрессом на дашборде

### Отслеживание обучения ИИ
1. Загрузите JSON-лог обучения модели (формат: массив объектов с полями `epoch`, `loss`, `accuracy`)
2. Посмотрите графики потерь и точности
3. Сравните разные эксперименты

### Генерация плана обучения
1. Перейдите в «AI План»
2. Укажите предмет, срок (недели), часы в неделю и метод обучения
3. Нажмите «Сделать мне план»
4. Примените сгенерированный план к предмету
